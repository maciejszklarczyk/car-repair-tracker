# Car Repair Tracker

Aplikacja do śledzenia historii napraw, kosztów eksploatacji i terminów serwisowych pojazdu. AI klasyfikuje typ naprawy na podstawie opisu.

Projekt kursowy — 10xDevs edycja 3.
